## 十一、Scene 与调用上下文 <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

有业务上下文时优先 `jobsGetWindowForView` / `jobsGetWindowForViewController`；控制器入口不会为了找窗口加载 view。需要指定 Scene 时使用 `jobsGetWindowForScene`。这些 UI 查询在后台线程返回 nil。

全局入口只搜索前台 active/inactive 的 `UIWindowScene`，忽略后台 Scene、隐藏/透明/非普通层级窗口；先完整搜索同状态 keyWindow，再按 session 标识排序选择普通窗口。`jobsGetMainWindowFromScenes` 可用于明确 Scene 集合与确定性回归；全局回退不能替代多窗口业务上下文。没有合适前台窗口时返回 nil。

`isiPhoneX_series()` 保留兼容入口，依据实际窗口 safe area 顶/底部而非机型表；新布局直接使用调用方 view 的 safe area。

[窗口回归](<./Tests/JobsWindowSelectionTests/JobsWindowSelectionTests.m>) 验证跳过后台 Scene、查找排序较后的 keyWindow、隐藏窗口回退、调用上下文和主线程边界。
