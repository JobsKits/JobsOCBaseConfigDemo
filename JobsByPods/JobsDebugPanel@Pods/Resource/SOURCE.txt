弱网调研：
https://developer.apple.com/library/archive/documentation/FileManagement/Conceptual/On_Demand_Resources_Guide/TestingPerformance.html
Apple 文档有独立 Network Link Conditioner 章节，明确开发设备从 Settings > Developer 进入、可开关和配置网络profile，附设备设置截图。
补充：https://developer.apple.com/videos/play/wwdc2021/10239/ 的英文完整Transcript包含 Network Link Conditioner；主标题为网络延迟优化，不如上述独立文档直观。
https://developer.apple.com/documentation/foundation/urlsessionconfiguration/protocolclasses
Apple 明确 custom URLProtocol 不能用于 background URLSession；URLProtocol 是 URLSession 请求协议处理扩展，无法覆盖全部 WebKit/底层 Socket/设备系统流量。
实现判断：普通 UIKit 调试 Pod 不承诺模拟全 App 真实带宽和丢包；此次按用户“不可行就不写”省略默认功能二，用开发者设置的 Network Link Conditioner 执行真弱网测试。

Debug-only 参考：
https://guides.cocoapods.org/syntax/podfile.html#pod
Podfile :configurations => ['Debug']；传递依赖默认全配置，需逐项核验。
https://developer.apple.com/documentation/xcode/adding-a-build-configuration-file-to-your-project
xcconfig 支持 config=Debug 条件。
保持 DEBUG 宏/Swift DEBUG 编译条件只属于 Debug 配置，避免 Release 被手工宏开启。
