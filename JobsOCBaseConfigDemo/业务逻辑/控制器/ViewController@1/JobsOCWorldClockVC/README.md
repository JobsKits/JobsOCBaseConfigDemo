## 一、行为与接入 <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

首页“功能实验室”保留项目来源副标题。深蓝#1565C0／白字悬浮时间（对比5.75:1）按本地化标题、等宽秒值和字体缩放测量，水平留白16pt、垂直10pt；安全区限制宽度，长标题换行增高，布局和语言改变时保留原吸附边。短按直接push本页，长按0.5秒后拖动，释放吸附全屏安全区最近一边；设置中的显隐偏好继续有效。本页不注册为Demo，不记最近使用，也不改变目录计数。

设备当前时区以独立圆角强调卡片置顶，大号当前时间随系统字号、窄宽可换行，城市／IANA／UTC偏移及日期星期完整保留；下面按当前日期的有效UTC偏移各取一个世界代表城市，巴黎和纽约优先其组，包含30／45分钟偏移。设备当前时区的偏移也保留在世界列表，城市名用系统本地化时区名称，日期使用完整日期与星期，秒值、UTC偏移和IANA标识同时显示。所有偏移由系统时区数据库计算，夏令时和系统时区变化时重新分组；这是系统本地数据，不请求远端API。

原生制式开关左侧标题反映当前值：关闭显示“24小时制”，开启显示“12小时制”，默认关闭；打开后各时区立即显示大写AM／PM，午夜为12:xx AM、正午为12:xx PM。选择保存在独立偏好键 `com.jobs.worldClock.uses12HourFormat`，不影响首页24小时浮钟，切换保持当前导航与滚动位置。

页面使用既有JobsTimer管理器，在可见且应用活跃时每秒更新可见行；离开、失活或进入后台移除定时器，返回前台重算并恢复。全局语言、主题和字体变化刷新文案及语义配色；空列表复用UIButtonModel图文空态和重新加载入口。
